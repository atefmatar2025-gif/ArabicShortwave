# موجات عربية — متابعة الإذاعات العربية على الموجات القصيرة عبر KiwiSDR

تطبيق أندرويد (Kotlin + Jetpack Compose) يعرض جدول البث العربي على الموجات القصيرة، وينبّهك عند بدء البث، ويشغّل المحطة مباشرة عبر أفضل مستقبل KiwiSDR متاح.

## ما يفعله التطبيق

| الميزة | كيف تعمل |
|---|---|
| جدول البث | يُنزَّل من جدول **EiBi** العام (`eibispace.de/dx/sked-<الموسم>.csv`) وتُستخرج منه الفترات العربية فقط (رمز اللغة `A`). يُحدَّث تلقائياً كل 3 أيام ويُختار ملف الموسم (A صيفي / B شتوي) حسب التاريخ. |
| التبويبات | على الهواء الآن، خلال 24 ساعة، المفضلة، الكل — مع بحث بالاسم أو التردد أو المنطقة. الأوقات بتوقيت UTC والتوقيت المحلي. |
| الإشعارات | منبّه دقيق واحد دائماً على أقرب بداية بث. تختار: المفضلة فقط / كل المحطات / إيقاف، ووقت التنبيه (عند البدء أو قبل 5/10/15 دقيقة). في الإشعار زر «استمع الآن». تُعاد الجدولة بعد إعادة تشغيل الهاتف. |
| اختيار المستقبل | تُنزَّل قائمة مستقبلات KiwiSDR العامة (`rx.linkfanel.net/kiwisdr_com.js`)، وتُستبعد المستقبلات المتوقفة أو الممتلئة أو التي لا تغطي التردد، ثم تُرتَّب حسب **القرب من المنطقة المستهدفة بالبث** (عمود Target في EiBi مثل ME، NAf) مع مراعاة نسبة الإشغال وجودة الإشارة SNR. |
| التشغيل | اتصال WebSocket مباشر ببروتوكول KiwiSDR (نفس بروتوكول `kiwiclient`) بتعديل AM أو SAM، وصوت PCM عبر AudioTrack في خدمة أمامية تستمر مع إطفاء الشاشة. |
| الانتقال لمستقبل آخر | يدوياً بزر «مستقبل آخر» أو باختيار أي مستقبل من القائمة، وتلقائياً إذا كان المستقبل مشغولاً/متوقفاً/لا يصل منه صوت، أو إذا بقيت الإشارة أضعف من S4 (‎-105 dBm) لمدة 20 ثانية. |

## البناء

**الطريقة الأسهل (دون تثبيت أي شيء):**
1. ارفع المجلد إلى مستودع جديد على GitHub.
2. سيعمل ملف `.github/workflows/build.yml` تلقائياً.
3. من تبويب **Actions** ← آخر تشغيل ← **Artifacts** نزّل `ArabicShortwave-debug-apk` وثبّته على الهاتف.

**عبر Android Studio:** افتح المجلد (File ← Open)، انتظر مزامنة Gradle، ثم Run. إذا طلب Gradle Wrapper اقبل إنشاءه (الإصدار 8.14.3).

المتطلبات: Android 8.0 (API 26) فأحدث.

## بنية الكود

```
app/src/main/java/com/arabicsw/kiwi/
├── data/
│   ├── ScheduleRepository.kt   تنزيل وتحليل جدول EiBi (العربية فقط) والتخزين المؤقت
│   ├── Broadcast.kt            نموذج فترة البث: على الهواء؟ البداية التالية؟ الأيام…
│   ├── KiwiDirectory.kt        قائمة مستقبلات KiwiSDR وترتيبها
│   ├── Geo.kt                  إحداثيات مناطق البث ورموز الدول ومسافة هافرسين
│   └── Prefs.kt                المفضلة والإعدادات
├── audio/KiwiClient.kt         عميل KiwiSDR (WebSocket + PCM/IMA-ADPCM + مقياس S)
├── player/PlayerService.kt     خدمة التشغيل الأمامية والانتقال التلقائي بين المستقبلات
├── alerts/                     جدولة المنبّهات والإشعارات وإعادة الجدولة بعد الإقلاع
└── ui/                         الواجهة العربية (من اليمين لليسار)
```

## ملاحظات

- مستقبلات KiwiSDR يديرها هواة متطوعون؛ لكل مستقبل عدد محدود من المستمعين (عادة 4–8) وقد يفرض بعضها حداً زمنياً للجلسة. التطبيق يعرّف نفسه باسم `ArabicSW`.
- جداول EiBi مجانية ومجتمعية، وقد تتغير المواعيد فعلياً قبل تحديث الجدول.
- اختيار المستقبل حسب «المنطقة المستهدفة» لأن الإشارة على الموجات القصيرة تُوجَّه إليها، فالمستقبل القريب منها غالباً يستقبلها أفضل من مستقبل قريب منك أنت.
